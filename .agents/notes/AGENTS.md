# AGENTS.md — Agent Notes

Agent Notes 是 agent 写的 RFC：记录理由、备选方案、后果、以及放弃了什么。完整的目录约定、格式与生命周期规则见 [`README.md`](README.md)。

**范围与排期是决定，不是计划文档。** 「第一个版本包含什么」有备选方案，所以它是一份 note。本仓库没有 roadmap 文件、没有迭代目录 —— `proposed/` 里的那些 note 就是待办清单。

**每写一份新 note 都要做取代检查。** 先搜树里有没有更早的 note 覆盖同一个决定或机制，更新它而不是新建一份重复的。

**永远不要把一份 note 改写成另一个决定。** 决定变了就新写一份并互相链接。就地改成它的反面，会让「我们当时为什么那样想」永久消失。

工作流见 [`rfs-agent-notes`](../skills/rfs-agent-notes/SKILL.md)；范围切分见 [`rfs-scope-cut`](../skills/rfs-scope-cut/SKILL.md)；写作标准见 [`rfs-prose-standard`](../skills/rfs-prose-standard/SKILL.md)。
